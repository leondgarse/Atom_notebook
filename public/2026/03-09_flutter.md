# Install
```sh
git clone https://github.com/flutter/flutter.git -b stable
export PATH="$PWD/flutter:$PATH"
```
```sh
flutter clean
flutter pub get
flutter doctor
flutter devices

flutter run -d linux

flutter build apk --release
```
- Use Dart for a flutter application and stitch loop skill for designing.
