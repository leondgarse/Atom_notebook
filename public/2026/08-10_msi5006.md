## C2PA
  - [Github contentauth/c2pa-rs](https://github.com/contentauth/c2pa-rs)
  ```sh
  pip install c2pa-python
  ```
  ```sh
  python -c 'import matplotlib.pyplot as plt; from skimage.data import chelsea; plt.imsave("my_image.jpg", chelsea())'
  ```
  创建一个名为 manifest.json 的文件，将以下内容复制进去。这个例子模拟了“我”（一个叫 Alice 的摄影师）用 Photoshop 创作了一张图片，并部分引用了另一张名为 original_photo.jpg 的素材
  ```json
  {
    // --- 1. 签名与证书信息（实操时需替换为自己的文件）---
    // 为了测试，c2patool 可以使用内置的自签名证书，但会显示警告。
    "alg": "es256",
    "private_key": "es256_private.key", // 你的私钥文件路径
    "sign_cert": "es256_certs.pem",     // 你的证书文件路径
    "ta_url": "http://timestamp.digicert.com", // 时间戳服务，用于证明签名时间

    // --- 2. 声明生成器（你是谁，用了什么工具）---
    "claim_generator": "MyPhotoApp v1.0", // 你的应用名称和版本

    // --- 3. 核心断言（Assertions）：说明发生了什么---
    "assertions": [
      {
        // 动作断言：说明执行了"创作"这个动作
        "label": "c2pa.actions.v2",
        "data": {
          "actions": [
            {
              "action": "c2pa.created", // 动作类型：创建
              "softwareAgent": "Adobe Photoshop 25.0", // 使用的软件
              "when": "2024-01-15T10:00:00+00:00" // ISO 8601时间戳
            }
          ]
        }
      },
      {
        // 作者断言：说明是谁创作的
        "label": "stds.schema-org.CreativeWork",
        "data": {
          "@context": "https://schema.org",
          "@type": "CreativeWork",
          "author": {
            "@type": "Person",
            "name": "Alice Photographer" // 作者名
          }
        }
      },
      {
        // 素材断言（Ingredients）：说明用了哪些原始素材
        "label": "c2pa.ingredients.v2",
        "data": {
          "ingredients": [
            {
              // 指向原始图片文件
              "relation": "componentOf",
              "identifier": "original_photo.jpg",
              "activeManifest": "dummy_manifest_id_123" // 可以引用原图的Manifest ID
            }
          ]
        }
      }
    ]
  }
  ```
