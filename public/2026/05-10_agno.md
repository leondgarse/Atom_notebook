## Starting
  - **Agno JWT** refers to the JSON Web Token (JWT) authentication and authorization middleware used in Agno (formerly Phidata), a framework for building AI agent applications. It is specifically designed for the AgentOS runtime, which allows developers to deploy agents as secure, production-ready APIs.The JWT middleware acts as a security layer, validating user identities and managing permissions in multi-user applications.
  - **RBAC** Role-Based Access Control. AgentOS validates JWT scopes against required permissions for each endpoint. Control who can access and run your agents, teams, and workflows.
  -  The framework is rarely the problem; lazy context engineering is. Both LangGraph and Agno reward developers who summarize, trim, and retrieve. Both punish developers who let context grow unbounded. The folklore that "framework X is wasteful" usually traces back to a team that didn't tune defaults, not a framework that's intrinsically broken.

  ```py
  import os

  # Set env vars BEFORE importing anything that uses them
  os.environ["OPENAI_BASE_URL"] = "http://localhost:8080/v1"
  os.environ["OPENAI_API_KEY"] = "not-needed"

  from agno.agent import Agent
  from agno.db.sqlite import SqliteDb
  from agno.os import AgentOS
  from agno.tools.workspace import Workspace

  workbench = Agent(
      name="local-llama-agent",                    # use a slug-friendly name
      model="openai-chat:unsloth/GLM-4.7-Flash",
      instructions="You are a helpful assistant. Be concise.",
      tools=[Workspace(".",
          allowed=["read", "list", "search"],
          confirm=["write", "edit", "delete", "shell"],
      )],  # read/write/edit/shell in this directory
      enable_agentic_memory=True,  # remembers across sessions
      add_history_to_context=True,  # include past runs
      num_history_runs=3,  # last 3 conversations
  )

  # Serve via AgentOS → streaming, auth, session isolation, API endpoints
  agent_os = AgentOS(agents=[workbench], tracing=True, db=SqliteDb(db_file="agno.db"))
  app = agent_os.get_app()

  if __name__ == "__main__":
      import uvicorn
      uvicorn.run(app, host="0.0.0.0", port=8000)
  ```

# Runtime
## Setup
  - The runtime is one of three layers of an agent platform:
    - the SDK to build.
    - the runtime to run.
    - the control plane to manage.
To ship agents to real users, you need to run them as a horizontally scalable, durable service reachable over an API. That’s what the runtime gives you.
AgentOS turns the Agent(...) into a FastAPI app with persistent sessions, JWT-based authentication, observability, and interfaces for Slack, Telegram, and more.
​

```py
# runtime_lab.py
import os

# Env vars BEFORE agno imports
os.environ["OPENAI_BASE_URL"] = "http://localhost:8080/v1"
os.environ["OPENAI_API_KEY"] = "not-needed"

from agno.agent import Agent
from agno.db.sqlite import SqliteDb
from agno.models.openai import OpenAIChat
from agno.os import AgentOS

# A couple of dead-simple tools to exercise tool calling
def add(a: int, b: int) -> int:
    """Add two integers."""
    return a + b

def get_weather(city: str) -> str:
    """Return fake weather for a city — for testing only."""
    return f"The weather in {city} is sunny and 28°C."

def get_user_profile_context(user_id: str) -> str:
    profiles = {"alice": "Alice prefers metric units."}
    return profiles.get(user_id, "")

agent = Agent(
    name="my-agent",                          # matches the URL slug in the docs' curl
    model=OpenAIChat(
        id="unsloth/GLM-4.7-Flash",
        base_url="http://localhost:8080/v1",
        api_key="not-needed",
    ),
    instructions=(
        "You are a helpful test assistant. Be concise. "
        "Use tools when they apply. Otherwise answer directly."
    ),
    context=[get_user_profile_context],
    tools=[add, get_weather],
)

agent_os = AgentOS(
    agents=[agent],
    tracing=True,
    db=SqliteDb(db_file="tmp/runtime_lab.db"),
)

# Or use PostgresDb
# from agno.db.postgres import PostgresDb
# db = PostgresDb(db_url="postgresql+psycopg://dash:dash@localhost:5432/dash")

app = agent_os.get_app()

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

